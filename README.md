# CIS25-Markov-Chain
Markov Chain Text Generator project for CIS25

Compile with:
g++ -std=c++11 -Wall -Wextra -pedantic main.cpp markov.cpp -o markov
• -Wall turns on a helpful set of warnings to catch common bugs and mistakes in your code.
• -Wextra turns on even more extra warnings for minor or tricky issues that -Wall misses.
• -pedantic forces the compiler to strictly follow official ISO C++ rules and reject non-standard code.
